# Letano Tech: header, nav and hero

Drop these files into your Next.js project (App Router, Tailwind CSS v4, TypeScript).
If your project uses a `src/` folder, put `app/`, `components/` and `lib/` inside `src/`.

    npm i framer-motion

Create `.env.local`:

    NEXT_PUBLIC_SITE_URL=https://your-domain.com

Replace the files `app/layout.tsx`, `app/page.tsx` and `app/globals.css` with these.
The `@/` import alias is the create-next-app default.
