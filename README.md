## Editing site content

Contact details, social links and section copy live in one place: `[path/to/contact.ts]`. To update your email, phone, WhatsApp number, hours or social links, edit that file and redeploy.

- WhatsApp numbers are digits only, with country code and no plus sign (for example `2348012345678`).
- Only social links with a URL are displayed.
